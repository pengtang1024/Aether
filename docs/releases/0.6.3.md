# Aether 0.6.3

**Settings became a page you can drive without reading documentation: every
daily choice is a preset, the rarely-touched ones moved into a collapsed
Advanced card, and a value edited by hand is shown as an unknown option
instead of being silently snapped to a neighbour. The daemon also survives a
full disk and a slow event subscriber.**

[![Made with Slint](https://raw.githubusercontent.com/slint-ui/slint/master/logo/MadeWithSlint-logo-whitebg.png)](https://slint.dev)

## Highlights

- **Preset-first settings.** Concurrency 3/5/10/16, per-task connections
  2/4/8/16, retries 0/3/5/10, global and BT upload sliders, proxy mode, IP
  protocol, theme/language/accent, schedule and notifications are dropdowns,
  sliders or switches. DNS, User-Agent, headers, BT port/blocklist/tracker,
  ffmpeg path, plugin source policy and the advanced RPC section live in an
  Advanced card that starts collapsed; the proxy address appears only in
  manual mode. Nothing has to be changed to get the recommended behaviour.
- **Out-of-range values are visible, not corrected.** A hand-edited
  `settings.json` value that is not on the preset ladder shows an explicit
  unknown-option entry, so the UI never claims a value the daemon is not
  actually using. Remaining text fields show their format example and the
  error under the field instead of dropping the submit.
- **A full disk no longer leaves a task running.** When SQLite itself cannot
  write, the failure is queued and replayed by the health tick; a permanent
  failure is not retried and its staging directory is removed, so the partial
  file stops occupying the quota it just ran out of.
- **A slow event subscriber cannot grow the daemon.** Each subscriber now has
  a bounded queue of 256 events; a client that stops reading loses events to a
  counter (the UI re-lists tasks periodically) instead of pinning unbounded
  heap.
- **Idle and hidden windows are cheap.** The tick compares the snapshot before
  repainting, and the clock and daemon poller park while the window is
  minimized, painting the last snapshot immediately on restore.

## Upgrading

- Debian/Ubuntu: `sudo dpkg -i aether_0.6.3_amd64.deb` (or `arm64`).
- AppImage, `.dmg` and the Windows build update as before.
- **Building from source now needs Rust 1.99** (was 1.92); the repository and
  CI pin 1.99.1. Binary releases are unaffected.

## Known limits

- BT web seeds (BEP 17/19) are ignored: the upstream library has no
  implementation, so a torrent only downloads from peers.
- Private (PT) trackers are not promised: most sites require a passkey and
  forbid third-party clients, so such a task fails like any tracker error.
- The browser extension is not in any store yet; the URL handler works, but
  there is nothing to install from the Chrome/Firefox galleries.
- The updater downloads the installer but does not run it: installing a system
  package needs root.
