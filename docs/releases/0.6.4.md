# Aether 0.6.4

**An alignment release. The tag, the release branch head and every published
artifact point at the same commit; the application is unchanged from 0.6.3.**

[![Made with Slint](https://raw.githubusercontent.com/slint-ui/slint/master/logo/MadeWithSlint-logo-whitebg.png)](https://slint.dev)

## What changed

- Nothing in the application. Feature work, behaviour and settings are exactly
  those of 0.6.3.
- `rust-toolchain.toml` pins the toolchain to 1.99.1. That pin was already part
  of the 0.6.3 build; in 0.6.4 it also reaches the tagged commit itself, so a
  checkout of the tag and the release artifacts are built from the same tree.

## Upgrading

- Debian/Ubuntu: `sudo dpkg -i aether_0.6.4_amd64.deb` (or `arm64`).
- AppImage, `.dmg` and the Windows build update as before.
- **Building from source needs Rust 1.99** (MSRV raised from 1.92 in 0.6.3);
  the repository and CI pin 1.99.1. Binary releases are unaffected.

## Known limits

- BT web seeds (BEP 17/19) are ignored: the upstream library has no
  implementation, so a torrent only downloads from peers.
- Private (PT) trackers are not promised: most sites require a passkey and
  forbid third-party clients, so such a task fails like any tracker error.
- The browser extension is not in any store yet; the URL handler works, but
  there is nothing to install from the Chrome/Firefox galleries.
