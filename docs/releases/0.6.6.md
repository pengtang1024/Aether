# Aether 0.6.6

**Updates stop asking for a password. The `.deb` now installs a verified
launcher; new versions land in your home directory, so after this one install
`sudo` is never needed again.**

[![Made with Slint](https://raw.githubusercontent.com/slint-ui/slint/master/logo/MadeWithSlint-logo-whitebg.png)](https://slint.dev)

## What changed

- `/usr/bin/aether`, `aether-cli`, `aether-daemon` and `aether-native-host` are
  now a small launcher (about 540 KB, ordinary permissions, not setuid). The
  real programs live in `/usr/lib/aether/seed` and are only what the package
  ships.
- The daemon downloads a new version into
  `~/.local/share/aether/versions/<version>/` and switches `current` to it.
  Nothing under `/usr` is touched, no privileged helper is involved, and no
  authorization dialog appears.
- Every start the launcher picks the highest version and verifies the user copy
  against the signed `update.json` (signature, manifest version matching the
  directory, and the program's SHA-256). A copy that does not check out is
  skipped and the package seed runs instead — a tampered binary is never
  executed.
- The update manifest gained a `runtimes` section with the four bare Linux
  programs, so the launcher knows exactly what each version should contain.
- The About panel says "ready; restart to apply (no password needed)" instead
  of asking for `sudo dpkg -i`.

## Upgrading

- Debian/Ubuntu: install this one by hand —
  `sudo apt install ./aether_0.6.6_amd64.deb` (or `arm64`). That is the last
  authenticated update: 0.6.6 and newer replace themselves silently.
- AppImage, `.dmg` and the Windows build update as before.

## Known limits

- Only the four programs update in user space. Plugins under
  `/usr/lib/aether/plugins` follow the package, so they stay at the installed
  version until the next `apt upgrade`. Plugins run as separate processes, so
  an older plugin tree still works with a newer program.
- The launcher trusts the package seed without a manifest check, because `dpkg`
  already guarantees it; only user-writable copies are verified.
