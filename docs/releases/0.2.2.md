# Aether 0.2.2

**Update checks tell you what happened.** A small follow-up to 0.2.1.

[![Made with Slint](https://raw.githubusercontent.com/slint-ui/slint/master/logo/MadeWithSlint-logo-whitebg.png)](https://slint.dev)

## Fixed

- "Check for updates" now reports its result. The check runs on a daemon
  worker thread, so the first toast said "checking…" and then disappeared;
  when the manifest fetch finished, only the small status line changed and a
  user watching the toast saw nothing. The window now waits for the daemon to
  leave the checking state and toasts the final outcome: up to date, a new
  version available (auto-download off), downloaded and ready to restart, or
  the error. A 150-second timeout guard covers a hung fetch.

## Notes

- The manifest fetch goes through GitHub; on a slow connection it can take
  about ten seconds before the result appears. The status line shows
  "checking" in the meantime.
- `.deb` auto-updates download and report `ready`; AppImage builds replace
  themselves atomically.
