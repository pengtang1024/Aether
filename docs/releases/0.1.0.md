**A native Material 3 download manager mockup — Rust + Slint, no WebView.**

[![Made with Slint](https://raw.githubusercontent.com/slint-ui/slint/master/logo/MadeWithSlint-logo-whitebg.png)](https://slint.dev)

This is the first desktop compatibility release. It is a UI mockup: downloads
are simulated and no network or file I/O is performed.

## Highlights

- Native Slint UI using the vendored Material 3 widget set, with a compact
  1040×700 canvas and a 900×600 minimum.
- Virtualized task table with search, status filters, live simulated speed,
  progress, status tags and row actions.
- New-download dialog (URL, path picker, segments, speed limit, note), with
  keyboard focus, Enter submit and Esc dismiss.
- Detail drawer with speed chart, chunk grid, file information, logs and BT
  peers.
- Five grouped settings cards and a simulated 12-task download engine.
- Transparent brand mark in the rail, frosted app icon for the desktop/dock,
  and platform icon sets.

## Downloads (withdrawn)

All assets for this release were removed. The original packages did not carry

## Compatibility

- **Linux:** Ubuntu 22.04+ / Debian 12+ / Raspberry Pi OS Bookworm; glibc 2.35+.
  Wayland and X11 are supported. The `.deb` installs the binary, desktop entry,
  hicolor icons and AppStream metadata under `/usr`.
- **Windows:** Windows 10/11 x86_64 and Windows 11 on Arm. The binaries use the
  static MSVC runtime, so no Visual C++ Redistributable is required.
- **macOS:** macOS 11+ on Apple Silicon and Intel via a universal binary.
- Slint uses a native winit backend with OpenGL and a software fallback. Chinese
  text uses system font fallback; Linux recommends `fonts-noto-cjk`.

## Install

Linux:

```bash
sudo apt install ./aether_0.1.0_amd64.deb
# or
chmod +x aether-0.1.0-linux-x86_64.AppImage
./aether-0.1.0-linux-x86_64.AppImage
```

Windows: run the `setup.exe` (Start Menu and optional desktop shortcut) or
extract the portable `.zip`.

macOS: open the `.dmg` and drag Aether to Applications. The build is ad-hoc
signed but **not notarized**. On recent macOS, right-click → Open may not be
enough; use System Settings → Privacy & Security → Open Anyway, or build from
source. Verify `SHA256SUMS` before opening.

## Known limitations

- Downloads, speeds, chunks, peers and logs are simulated.
- Settings are in-memory only; there is no persistence or resume.
- macOS and Windows packages are not code-signed/notarized.
- Mobile (Android/iOS) and Web builds are not included.
- The window is desktop-oriented (900×600 minimum).
