# Aether 0.6.2

**Every long operation now shows what it is doing: app updates, plugin updates
and plugin installs report real progress, and the plugin-settings dialog reads
like the rest of Settings instead of a stack of unaligned boxes.**

[![Made with Slint](https://raw.githubusercontent.com/slint-ui/slint/master/logo/MadeWithSlint-logo-whitebg.png)](https://slint.dev)

## Highlights

- **Progress where the work happens.** An app-update download fills a bar in
  the About panel with a percentage; a plugin update or install fills one on
  the plugin card and names the plugin it is on (`正在更新 http · 1/3`). Work
  that has no measurable fraction — checking for updates, reading a manifest —
  sweeps the same track instead of leaving a dead bar.
- **The plugin dialog is a form, not a stack.** Label column on the left with
  its hint underneath, control column flush right, dividers between rows,
  left-aligned section headers, and a `已保存` badge on values loaded from
  storage. The card hugs its content, so a one-field plugin no longer opens a
  220px panel with a 130px dead band above the buttons.
- **The tray icon is drawn for a tray.** The plated app icon (12% inset,
  translucent background) read one size small and washed out on light panels;
  it is replaced by a full-bleed glyph at 64px and 128px.
- **`media`/`rtmp` plugins carry their own ffmpeg.** Linux packages now ship a
  minimal ffmpeg 9.0.2 built from source (~13 MB), so remuxing and RTMP capture
  work right after installing the plugin. Windows and macOS still use a
  user-installed ffmpeg.
- **The global speed limit became a fair share.** It is split across running
  tasks and recomputed when tasks start, finish, or either limit changes; a
  task's own limit is capped at its share instead of overriding the global cap.
- **aria2 compatibility hardened.** `changeGlobalOption` patches are sent
  nested again, `getOption` falls back to the global download directory, and
  `shutdown`/`forceShutdown` replies are flushed before the daemon exits
  instead of arriving truncated.

## Upgrading

- Debian/Ubuntu: `sudo dpkg -i aether_0.6.2_amd64.deb` (or `arm64`).
- AppImage, `.dmg` and the Windows build update as before.
- Plugin packages are re-staged by the package. Existing user-installed plugins
  keep working; the new bundled ffmpeg only affects the packaged
  `media`/`rtmp` plugins.

## Known limits

- The updater downloads the installer but does not run it: installing a system
  package needs root.
- Plugin credentials are still stored unencrypted in the 0600 SQLite database;
  `multiline` plugin settings still render as a single-line field.
- The plugin dialog centres within the content area (right of the icon rail),
  not the window frame.
- `logs` detail sections are declared in plugin manifests but not rendered yet.
