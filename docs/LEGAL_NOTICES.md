# 使用与合规提示

> 本文是产品行为说明，不是法律意见。下载、录制、做种和云盘访问是否合法取决于
> 内容、来源、用户所在司法辖区和服务条款；用户对自己发起的操作负责。

## 1. 内容与来源

Aether 是通用下载工具，不托管、不索引、不提供内容。用户应只下载自己有权访问和
保存的内容，并遵守来源网站/服务的条款与当地法律。项目明确不实现：

- 绕过 DRM、付费墙、登录、验证码或反爬机制；
- 私有加速/离线通道（如迅雷私有协议）；
- 云端风控、会员或地域限制的绕过。

## 2. BitTorrent 与做种

BT 任务会连接 tracker、DHT 和陌生 peer，**用户的 IP 地址对它们可见**；做种还会
向他人上传数据。上传受版权法约束的程度因司法辖区而异，部分地区的通知/断网规则
更严格。

- `bt_seed_ratio` / `bt_seed_minutes` 默认 `0`（下载完成即停止做种）；
- 需要做种时请自行确认内容授权、tracker 规则与当地法律；
- 可使用代理、VPN 和屏蔽列表降低暴露，但这不是法律豁免；
- 恶意种子仍可能包含路径穿越或超大文件，Host 会做路径/空间校验，但用户不应
  下载来源不明的可执行内容。

## 3. 流媒体、录屏与外部工具

`extractor` 插件调用用户自行安装的 **yt-dlp**，`rtmp`/`media` 转封装调用用户
自行安装的 **ffmpeg**。它们不随 Aether 分发，各自按其许可证（yt-dlp 为
GPL-3.0-or-later；ffmpeg 的许可取决于构建选项）由用户自行取得和遵守。YouTube
等平台的服务条款通常禁止未经授权的下载；录制直播/会议也可能涉及肖像权、隐私权
和著作权。请自行取得授权。

Aether 不包含 H.264/AAC 等编解码器，也不承担用户安装的第三方工具产生的专利许可
义务。

## 4. 云盘与 OAuth

Google Drive、OneDrive、Dropbox、百度网盘、阿里云盘等插件只使用官方 API/公开
分享链接，不抓取 Cookie、不绕过会员或风控。OAuth 客户端 ID/Secret 由用户自行
在服务商处注册；插件不内置任何凭据。使用即表示用户同意相应服务商的 API 条款和
配额限制。

## 6. 出口管制与加密

Aether 使用标准 TLS、Ed25519 签名和哈希算法（通过 ring/aws-lc 等通用库），属于
公开可获取的开源软件，通常适用大众市场/公开源代码的出口豁免；但用户仍应遵守
所在国家/地区的出口管制与制裁法律，不得将其用于受制裁主体或受限用途。更新检查
和发布托管使用 GitHub，受其服务条款约束。

## 7. 无障碍与消费者保护

项目按 WCAG 方向做了语义标注，但尚未完成屏幕阅读器真机认证。若在欧盟作为面向
消费者的产品/服务销售，请评估《欧洲无障碍法案》(EAA) 等适用要求。发布文案不应
声称“已沙箱隔离”“绝对安全”或“支持所有网站”；当前是进程隔离 + 能力声明，不是
OS 级沙箱。
